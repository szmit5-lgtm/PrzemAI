# PrzemAI

PrzemAI to rozwijana aplikacja asystenta AI do pracy z dokumentami, spotkaniami i zadaniami.

## Zakres projektu

- Analiza dokumentów i historia zapisanych analiz.
- Obsługa spotkań oraz przygotowywanie podsumowań.
- Menedżer zadań.
- Rozwijane moduły agentów i integracji.

Funkcje mogą być na różnym etapie wdrożenia. Samo istnienie modułu nie oznacza gotowości produkcyjnej.

## Zasady bezpiecznego rozwoju

1. Pracuj nad zmianami na gałęzi rozwojowej, a nie bezpośrednio na `main`.
2. Przed zmianą sprawdź stan GitHub, testów CI oraz wdrożeń Vercel i Railway.
3. Wprowadzaj małe, możliwe do zweryfikowania poprawki.
4. Nie zmieniaj produkcyjnej bazy danych ani backendu produkcyjnego bez wyraźnej zgody.
5. Nie zapisuj sekretów, tokenów ani haseł w repozytorium.
6. Po zmianie sprawdź wynik testów i wdrożenia; odróżniaj pomyślny build od testów funkcjonalnych.

## Status bety

Status funkcji i wdrożeń należy potwierdzać na bieżąco w GitHub, CI, Vercel i Railway. Ten plik nie jest automatycznym raportem stanu środowisk.
